# Các câu lệnh điều khiển hệ thống (Vinh Gia Workflow)

### 1. Lệnh Xây dựng Component Hệ thống
"/sys_build: Hãy phân tích và xây dựng component [Tên component]. 
- Đầu vào: Định nghĩa Interface cho dữ liệu.
- Xử lý: Sử dụng Tailwind CSS, cấu trúc logic Clean Code.
- Đầu ra: Component hoàn chỉnh, hỗ trợ đa ngôn ngữ Tiếng Việt, tuân thủ theme hệ thống."

### 2. Lệnh Tối ưu hóa & Refactor
"/sys_refactor: Hãy refactor đoạn code sau để tăng hiệu suất và tính hệ thống: [Paste code].
- Yêu cầu: Tách nhỏ logic, kiểm tra alias '@', đảm bảo tính nhất quán với cấu trúc của Vinh Gia Portal."

### 3. Lệnh Kết nối Dữ liệu (Backend-to-Frontend)
"/sys_api: Tạo một service trong [File service] để gọi API cho module [Tên module].
- Cấu trúc: Sử dụng TypeScript Interface cho dữ liệu trả về từ SQL Server.
- Xử lý lỗi: Thêm các thông báo lỗi bằng Tiếng Việt thân thiện."
